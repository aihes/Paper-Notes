➡ 写入机制 (STM 到 LTM)

  • 自动摘要 (Summarization): 对话结束或 Context 满时，将对话压缩为摘要存入 LTM。
  • 反思 (Reflection): (Generative Agents) 从原始对话中提炼出“高级见解”存入。
  • 自我编辑 (Self-Editing): (Letta) Agent 主动调用 `archival_memory.insert()` 保存关键事实。

⬅ 读取机制 (LTM 到 STM)

  • 语义检索 (RAG): 根据用户当前 Query，计算向量相似度，自动拉取相关历史。
  • 显式查询 (Explicit Query): Agent 发现信息缺失，主动调用 `search()` 查找特定档案。
  • 分页 (Paging): (OS 隐喻) 将长文本分块，Agent 像翻书一样将不同块换入 Context。
