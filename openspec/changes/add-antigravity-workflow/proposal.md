# Change: Add Antigravity Session Archival Workflow

## Why
Google Antigravity is an agentic workspace environment. Users need a standardized way to archive session contexts, plans, tasks, and walkthroughs from Antigravity sessions into the local OpenSpec change management system. This ensures that valuable conversation context and agent reasoning are preserved and versioned.

## What Changes
- Add a new workflow document `docs/antigravity_session_archive_workflow.md` (written in Chinese).
- The workflow defines steps to organize session info (Plan, Task, Walkthrough, Context) and save it as an OpenSpec change.

## Impact
- **Affected specs**: `documentation`
- **Affected files**: `docs/antigravity_session_archive_workflow.md`
