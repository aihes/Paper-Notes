## ADDED Requirements
### Requirement: Antigravity Session Archive Workflow
The system SHALL provide a documented workflow for archiving Google Antigravity session contexts into the OpenSpec change management system.

#### Scenario: Archiving a session
- **WHEN** a developer wants to preserve an Antigravity agent session
- **THEN** they follow the `docs/antigravity_session_archive_workflow.md` guide to extract Plan, Task, Walkthrough, and Context
- **AND** save it as a new structured OpenSpec change proposal
- **AND** update the relevant system specifications using OpenSpec Deltas.
